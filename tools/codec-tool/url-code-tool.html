URL 编解码

输入待处理的文本内容，点击「编码」将特殊字符转换为 URL 安全格式（%xx），或点击「解码」将 %xx 格式还原为原始字符。编码结果自动复制到剪贴板。

将特殊字符转换为 %xx 格式，确保 URL 安全传输
支持中文、日文、韩文等各种 Unicode 字符
编码或解码成功后结果自动复制到剪贴板
所有处理在浏览器本地完成，数据不会上传到服务器
